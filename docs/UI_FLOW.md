# UI フロー

## メインウィンドウ

1. 「動画を開く」ボタン → `OpenFileDialog` → MP4 を選択
2. 動画が再生開始される
3. 気になるシーンで `D` キーを押す → ケースが作成される（±20s/+30s のクリップ）
4. 右パネルでフィールドを入力 → 「フィールドを保存」
5. `G` / `B` / `N` で結果を設定
6. 講義カードが自動更新される
7. 「比較ビュー」ボタンで 2 画面比較ウィンドウを開く

## キーボードショートカット

| キー | 動作 |
|------|------|
| D    | ケースを作成（Decision Point） |
| G    | 結果を「良い」に設定 |
| B    | 結果を「悪い」に設定 |
| N    | 結果を「中立」に設定 |
