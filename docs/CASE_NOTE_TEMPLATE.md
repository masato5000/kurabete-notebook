# ケースノート テンプレート

各ケースには以下のフィールドを記録します:

| フィールド | キー | 説明 |
|---|---|---|
| 場面 | `場面` | その場面の状況説明 |
| 判断 | `判断` | プレイヤーが下した判断 |
| 結果 | outcome | Good / Bad / Neutral |
| メモ | memo | 自由記述 |

## 講義カードの生成

`LectureCardService.Generate(Case c)` によって以下のフォーマットで出力されます:

```
【ケース #1】
結果: ✓ 良い
タイムスタンプ: 00:05:30
メモ: ポジショニングが良かった
場面: 2v2 の状況
判断: 後退してチームメイトを待った
```
