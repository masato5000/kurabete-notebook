# 使い方ガイド

## 0. かんたん起動（自動スクリプト）

> **「コマンドはよくわからない」という方はここだけ読めば OK です。**

### 手順

1. .NET 8 SDK をインストールしていない場合は先にインストールしてください。  
   → [https://dotnet.microsoft.com/download/dotnet/8.0](https://dotnet.microsoft.com/download/dotnet/8.0)

2. ブラウザで [https://github.com/masato5000/kurabete-notebook](https://github.com/masato5000/kurabete-notebook) を開き、  
   緑色の **「Code」** → **「Download ZIP」** でソースコードを取得します。

3. ZIP を右クリック →「すべて展開」で任意のフォルダーに解凍します。

4. 解凍したフォルダーを開くと、次のようなファイル一覧が見えます。  
   **`start.bat`** はフォルダーの一番上の階層（ルート）にあります。

   ```
   kurabete-notebook-main\          ← 解凍してできるフォルダー
   ├── start.bat                    ← ★ これをダブルクリック！
   ├── README.md
   ├── docs\
   ├── src\
   └── ...
   ```

   **`start.bat`** をダブルクリックしてください。

   - ビルドとアプリの起動が自動で行われます。
   - 黒いウィンドウ（コマンドプロンプト）が開き、進捗が表示されます。
   - 「[OK] ビルド成功。アプリを起動します...」と表示されたらメインウィンドウが開きます。

> **エラーが表示された場合:** 画面のメッセージを確認してください。多くの場合 .NET 8 SDK のインストールで解決します。

## 1. ビルドと起動

### 必要なもの
- Windows 10 以降
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)（インストール済みであれば次のステップへ）

---

### ステップ A — ソースコードを入手する

ソースコードを取得する方法は 2 通りあります。どちらか簡単な方を選んでください。

#### 方法 1: ZIP でダウンロード（Git 不要・おすすめ）

1. ブラウザで [https://github.com/masato5000/kurabete-notebook](https://github.com/masato5000/kurabete-notebook) を開きます。
2. 緑色の **「Code」** ボタンをクリックし、**「Download ZIP」** を選択します。
3. ダウンロードした ZIP ファイルを右クリック →「すべて展開」で任意のフォルダーに解凍します。  
   （例: `C:\Users\あなたの名前\Downloads\kurabete-notebook`）

#### 方法 2: Git でクローン

[Git for Windows](https://gitforwindows.org/) がインストール済みの場合:

1. スタートメニューで **「PowerShell」** または **「コマンドプロンプト」** を検索して開きます。
2. 以下のコマンドを貼り付けて Enter を押します:

```powershell
git clone https://github.com/masato5000/kurabete-notebook.git
```

3. `kurabete-notebook` フォルダーが作成されます。

---

### ステップ B — ターミナル（コマンドプロンプト）を開いてフォルダーへ移動する

1. スタートメニューで **「PowerShell」** または **「コマンドプロンプト」** を検索して開きます。
2. 解凍 / クローンしたフォルダーへ移動します。  
   （パスはご自身の展開先に合わせて変更してください）

```powershell
cd C:\Users\あなたの名前\Downloads\kurabete-notebook
```

> **ヒント:** エクスプローラーでフォルダーを開き、アドレスバーに `powershell` と入力して Enter を押すと、そのフォルダーで PowerShell が開きます。

---

### ステップ C — ビルドする

ターミナルに以下を入力して Enter を押します:

```powershell
dotnet build
```

`Build succeeded` と表示されれば成功です。

> **エラーが出た場合:** `dotnet --version` を実行して `8.x.x` と表示されるか確認してください。表示されない場合は SDK が正しくインストールされていません。

---

### ステップ D — アプリを起動する

```powershell
dotnet run --project src/KurabeteNotebook.App
```

メインウィンドウが表示されたら準備完了です。次のセクションの操作手順へ進んでください。

---

## 2. 基本的な使い方（ステップバイステップ）

### ステップ 1 — 動画を開く

1. アプリを起動するとメインウィンドウが表示されます。
2. 左上の **「動画を開く」** ボタンをクリックします。
3. ファイル選択ダイアログが開くので、振り返りたい **MP4 ファイル** を選択します。
4. 動画が左パネルに読み込まれ、自動的に再生が始まります。

> **ヒント:** 動画ファイルは元の場所を参照するだけで、コピーはされません。

---

### ステップ 2 — ケース（判断ポイント）を作成する

1. 動画を再生しながら、振り返りたいシーンになったら **`D` キー** を押します。
2. 現在の再生位置を中心に、前 20 秒〜後 30 秒の範囲をカバーするケースが自動作成されます。
3. 画面下部のケース一覧（グリッド）に新しい行が追加されます。

> **ヒント:** `D` キーはテキストボックスにフォーカスがない状態で押してください。

---

### ステップ 3 — 結果を設定する

ケースを作成したら、そのプレイが良かったか悪かったかをキーで素早く記録します。

| キー | 結果 |
|------|------|
| `G`  | ✓ 良い（Good） |
| `B`  | ✗ 悪い（Bad） |
| `N`  | ─ 中立（Neutral） |

---

### ステップ 4 — ケースの詳細を記録する

1. ケース一覧の行をクリックして選択します。
2. 右パネルの入力欄にメモを記入します:
   - **場面**: そのシーンの状況（例: 「2v2 の守り場面」）
   - **判断**: 自分がとった行動（例: 「後退してチームメイトを待った」）
   - **メモ**: 自由記述
3. **「フィールドを保存」** ボタンをクリックして保存します。

---

### ステップ 5 — 講義カードを確認する

フィールドを保存すると、右パネル下部に **講義カード** が自動生成されます。

```
【ケース #1】
結果: ✓ 良い
タイムスタンプ: 00:05:30
メモ: ポジショニングが良かった
場面: 2v2 の状況
判断: 後退してチームメイトを待った
```

これをコピーして Discord や Notion に貼り付けることができます。

---

### ステップ 6 — 比較ビューで 2 ケースを並べる

1. **「比較ビュー」** ボタンをクリックします。
2. 別ウィンドウが開き、2 つの動画を並べて再生できます。
3. 各プレイヤーの再生・一時停止ボタン、または **同期再生** ボタンを使います。

---

## 3. データの保存場所

すべてのデータはローカルの SQLite データベースに保存されます:

```
%USERPROFILE%\Documents\kurabete-notebook\library.db
```

バックアップしたい場合はこのファイルをコピーしてください。

---

## 4. キーボードショートカット一覧

| キー | 動作 |
|------|------|
| `D`  | 現在位置にケース（Decision Point）を作成 |
| `G`  | 選択中ケースの結果を「良い」に設定 |
| `B`  | 選択中ケースの結果を「悪い」に設定 |
| `N`  | 選択中ケースの結果を「中立」に設定 |

> **注意:** テキストボックスが選択されているとショートカットが効きません。動画プレイヤーや空白エリアをクリックしてからキーを押してください。

## 5. よくある質問

**Q: 対応している動画フォーマットは？**  
A: 現在は MP4（H.264）に対応しています。Windows Media Foundation が対応しているコーデックであれば再生可能です。

**Q: データはクラウドに送られますか？**  
A: いいえ。このアプリはインターネット通信を一切行いません。すべてのデータはローカルに保存されます。

**Q: 動画ファイルを移動・削除したらどうなりますか？**  
A: ケースのメモや設定はデータベースに残りますが、動画は再生できなくなります。ファイルを元の場所に戻すか、新たに同じファイルを開き直してください。
