# 使い方ガイド

## 1. ビルドと起動

### 必要なもの
- Windows 10 以降
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)

### ビルド手順

```bash
git clone https://github.com/masato5000/kurabete-notebook.git
cd kurabete-notebook
dotnet build
```

### 起動

```bash
dotnet run --project src/KurabeteNotebook.App
```

---

## 2. 基本的な使い方（ステップバイステップ）

### ステップ 1 — 動画を開く

1. アプリを起動するとメインウィンドウが表示されます。
2. 左上の **「動画を開く」** ボタンをクリックします。
3. ファイル選択ダイアログが開くので、振り返りたい **MP4 ファイル** を選択します。
4. 動画が左パネルに読み込まれ、自動的に再生が始まります。

> **ヒント:** 動画ファイルは元の場所を参照するだけで、コピーはされません。

---

### ステップ 2 — ケース（判断ポイント）を作成する

1. 動画を再生しながら、振り返りたいシーンになったら **`D` キー** を押します。
2. 現在の再生位置を中心に、前 20 秒〜後 30 秒の範囲をカバーするケースが自動作成されます。
3. 画面下部のケース一覧（グリッド）に新しい行が追加されます。

> **ヒント:** `D` キーはテキストボックスにフォーカスがない状態で押してください。

---

### ステップ 3 — 結果を設定する

ケースを作成したら、そのプレイが良かったか悪かったかをキーで素早く記録します。

| キー | 結果 |
|------|------|
| `G`  | ✓ 良い（Good） |
| `B`  | ✗ 悪い（Bad） |
| `N`  | ─ 中立（Neutral） |

---

### ステップ 4 — ケースの詳細を記録する

1. ケース一覧の行をクリックして選択します。
2. 右パネルの入力欄にメモを記入します:
   - **場面**: そのシーンの状況（例: 「2v2 の守り場面」）
   - **判断**: 自分がとった行動（例: 「後退してチームメイトを待った」）
   - **メモ**: 自由記述
3. **「フィールドを保存」** ボタンをクリックして保存します。

---

### ステップ 5 — 講義カードを確認する

フィールドを保存すると、右パネル下部に **講義カード** が自動生成されます。

```
【ケース #1】
結果: ✓ 良い
タイムスタンプ: 00:05:30
メモ: ポジショニングが良かった
場面: 2v2 の状況
判断: 後退してチームメイトを待った
```

これをコピーして Discord や Notion に貼り付けることができます。

---

### ステップ 6 — 比較ビューで 2 ケースを並べる

1. **「比較ビュー」** ボタンをクリックします。
2. 別ウィンドウが開き、2 つの動画を並べて再生できます。
3. 各プレイヤーの再生・一時停止ボタン、または **同期再生** ボタンを使います。

---

## 3. データの保存場所

すべてのデータはローカルの SQLite データベースに保存されます:

```
%USERPROFILE%\Documents\kurabete-notebook\library.db
```

バックアップしたい場合はこのファイルをコピーしてください。

---

## 4. キーボードショートカット一覧

| キー | 動作 |
|------|------|
| `D`  | 現在位置にケース（Decision Point）を作成 |
| `G`  | 選択中ケースの結果を「良い」に設定 |
| `B`  | 選択中ケースの結果を「悪い」に設定 |
| `N`  | 選択中ケースの結果を「中立」に設定 |

> **注意:** テキストボックスが選択されているとショートカットが効きません。動画プレイヤーや空白エリアをクリックしてからキーを押してください。

## 5. よくある質問

**Q: 対応している動画フォーマットは？**  
A: 現在は MP4（H.264）に対応しています。Windows Media Foundation が対応しているコーデックであれば再生可能です。

**Q: データはクラウドに送られますか？**  
A: いいえ。このアプリはインターネット通信を一切行いません。すべてのデータはローカルに保存されます。

**Q: 動画ファイルを移動・削除したらどうなりますか？**  
A: ケースのメモや設定はデータベースに残りますが、動画は再生できなくなります。ファイルを元の場所に戻すか、新たに同じファイルを開き直してください。
