# くらべて上手くなるゲーム見返しノート

**表示名: くらべて上手くなる**

ゲームのプレイ動画（MP4）を振り返り、「判断ポイント（ケース）」を記録・比較することで上達を促す Windows デスクトップアプリです。

👉 **[詳しい使い方はこちら → docs/USAGE.md](docs/USAGE.md)**

## 主な機能

- MP4 動画を読み込み、再生・シークができます。
- `D` キーを押すと現在の再生位置を中心に Decision Point（ケース）を作成します（前 20 秒〜後 30 秒）。
- ケースの結果を素早く設定できます：`G`＝良い、`B`＝悪い、`N`＝中立。
- ケースはローカル SQLite に保存されます。
- 右パネルのフィールドでリサーチテンプレート（場面・判断・メモ）を記録できます。
- 選択中のケースから「講義カード」を自動生成します。
- 2 つのケースを並べて比較できる比較ビューがあります（スタブ）。

## キーボードショートカット

| キー | 動作 |
|------|------|
| `D`  | ケースを作成（Decision Point） |
| `G`  | 結果を「良い」に設定 |
| `B`  | 結果を「悪い」に設定 |
| `N`  | 結果を「中立」に設定 |

## データの保存場所

```
%USERPROFILE%\Documents\kurabete-notebook\library.db
```

動画ファイルはオリジナルの場所を参照します（コピーされません）。

## プライバシー

このアプリはインターネット通信を一切行いません。すべてのデータはローカルに保存されます。

## ビルド方法

前提: .NET 8 SDK をインストールしていること。

### かんたん起動（おすすめ）

リポジトリのルートにある **`start.bat`** をダブルクリックするだけでビルドと起動が自動で行われます。

### 手動でビルドする場合

```bash
dotnet build
```
